# Değerlendirme — ck0080 String Toplama Tuzağı

1. "3" ve "5" girince neden "35" çıktı, "8" değil?
   > Cevap notu: x ve y string tipinde, string + string sayısal toplama değil metin
   > birleştirmesi yapar.

2. Düzelttiğin kodda doğru toplamı nasıl aldın?
   > Cevap notu: `Convert.ToInt32(x) + Convert.ToInt32(y)` — ck0030'daki çözümün aynısı,
   > öğrenci aynı yöntemi burada da uygulayabilmiş olmalı.
