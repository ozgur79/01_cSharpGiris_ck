# Değerlendirme — ck0290

1. ck0280'de işlem seçimi "1,2,3,4" rakamlarıyla, burada '+','-','*','/' sembolleriyle
   yapılıyor. İkisi de aynı işi mi görüyor?
   (Özgür için: evet, ikisi de "hangi işlem yapılacak" kararını veriyor; fark sadece
   kullanıcının hangi tuşa basacağı — rakam mı sembol mü.)

2. `char secim` yerine `string secim` kullanılsaydı, `secim == '+'` satırı derlenir miydi?
   (Özgür için: hayır — `'+' ` tek tırnakla char sabiti, `"+"` çift tırnakla string
   sabitidir; char değişkeni string sabitiyle karşılaştırılamaz, tür uyuşmazlığı hatası
   alınır.)
