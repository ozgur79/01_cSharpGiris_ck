# Değerlendirme — ck0220

1. `x + "+" + y + "=" + (x + y)` satırında `(x + y)` neden parantez içinde?
   (Özgür için: parantez olmasa `+` işlemleri soldan sağa sırayla, string birleştirme
   olarak çalışırdı; `x + y` ayrı hesaplanmazdı. Parantez önce sayısal toplamayı
   yaptırıyor, sonucu sonra yazıya ekliyor.)

2. x=9, y=2 iken "/" satırının sonucu ne çıkar, neden?
   (Özgür için: 4 çıkar, 4.5 değil — ck0060'taki kural: iki int'i bölünce küsurat atılır,
   sonuç yine int'tir.)
