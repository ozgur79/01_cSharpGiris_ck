# Değerlendirme — ck0695

1. Neden dizi 4 elemanlık ama döngü sadece 3 kez dönüyor?
   (Özgür için: ilk 3 eleman rastgele üretilecek, 4. eleman (indis 3) döngüden
   SONRA elle toplamla dolduruluyor — döngü 4 kez dönseydi 4. eleman da rastgele
   üretilip toplam üzerine yazılırdı.)

2. sayilar[3] = toplam; satırı döngüden önce yazılsaydı ne olurdu?
   (Özgür için: toplam henüz 0 olurdu (hiç sayı eklenmemiş), sayilar[3] hep 0 kalırdı
   — bu satırın döngüden SONRA gelmesi, toplamın tamamlanmış olmasını garanti eder.)
